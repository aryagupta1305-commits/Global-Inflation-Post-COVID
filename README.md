# Global Inflation: Post-COVID Trends

An Excel-based macroeconomic analysis examining inflation, interest rates, GDP growth, unemployment, and money supply across 20 countries in the post-COVID period.

## Dataset

Monthly macroeconomic indicators (2020 onward) per country, including:

- Inflation rate, interest rate, oil price, GDP growth
- Unemployment rate, money supply, exchange rate (USD)
- Food price index, supply chain index

## Structure

- **Data Sheet** — raw monthly data by country
- **Tabular Analysis** — pivot tables summarizing average inflation rate, GDP growth, money supply, exchange rate, food price index, and supply chain index by country
- **Dashboard** — visual summary including average inflation rate by country (pie chart), relationship between money supply/exchange rate/GDP growth over time, GDP/unemployment/interest rate trends, and year-over-year inflation rate comparisons across all countries analyzed

## Method

Built entirely in Excel using pivot tables for country-level aggregation and dashboard-style charts (pie, line, stacked bar) linked to the pivoted data for interactive filtering.

## Tools

Excel — pivot tables, conditional formatting, dashboard charts
